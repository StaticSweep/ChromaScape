# SC-810 Phase 2 — tracked-artifact classification (micro6-sc810-package, 2026-09-11)

## Scope

Full `git ls-files` inventory of `micro6-sc810-package`, extending the earlier cleanup
(commit `0325bc64fd`, which removed the 45 files explicitly named in the original checklist:
`build.log`, `hs_err_pid*.log`, `micro6*.log`, `replay_pid*.log`, 18 stray `microbot-*.jar`
copies) to everything else under cache/build/runtime-shaped tracked paths.

## Method

For every candidate: identified the introducing commit, searched `build.gradle.kts` and
source for references, and classified before removing anything. Nothing was deleted by
wildcard — the final removal list was built from verified, individually-checked tracked
paths only.

## Not touched

- `gradle/wrapper/gradle-wrapper.jar` — standard Gradle Wrapper convention, required to
  bootstrap `./gradlew` without a system Gradle install. Not generated by this project's own
  build; not in scope.
- `micro6-harness/golden/{pass,fail-seeded}/manifest-hash.txt` and any other file under
  `micro6-harness/golden/` — these are the actual checked-in fixtures `GoldenManifestTest`
  compares against; confirmed real, referenced, required.
- Anything outside `micro6-sc810-package`, and anything not matching a verified
  generated/orphaned pattern above (no unrelated operator work touched).

## Secret scan

`git ls-files` filtered for `.pem`, `.pk8`, `.p12`, `.pfx`, `id_rsa`, `id_ed25519`, `.env`,
`secret`, `credential` (excluding test/example/sample paths) returns only legitimate source
files whose names happen to contain "secret" — `SecretRedactor.java` (a redaction utility)
and the `secretsofthenorth` quest-helper package (a real OSRS quest name). No actual secret
or credential material is tracked.
