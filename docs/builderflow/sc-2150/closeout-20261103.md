## 2. Changed behaviour

1. **Automatic assisted track.** `Generate automatic cursor track` schedules `visual/v1` without an
   annotation attestation, reports truthful stages (`ANALYSIS_SAMPLES`, `ANALYSIS_TRACKING`) and reuses
   an equivalent completed analysis instead of re-queueing.
2. **Server-owned profile.** `GET /capabilities.analysisProfile` exposes the resolved pack, digest,
   sampling settings, thresholds, hotspot and enforced storage; a request may only name the configured
   pack, and a missing/mismatched pinned template fails scheduling closed.
3. **Cleanup and truthful failures.** A confirmed workspace close removes the ext2 image *and* the empty
   mountpoint; `QUOTA_EXCEEDED` has its own bounded public message; the observability queue block is
   restored.
4. **Local operator principal.** `fedora-development` can serve same-machine operator calls when
   `chromascape.local.operator.principal.enabled` is explicitly set; ignored for every other profile and
   never derived from a request header.
5. **Fedora launcher** forwards `CHROMASCAPE_MOUSE_VIDEO_*` and the operator flag from `.env.local`, so
   the assisted profile is durable machine configuration, not an inherited shell.

## 7. Remaining limitations

- Assisted suggestions are unqualified detector output; 592/597 visible on one clip is coverage, not
  accuracy.
- The 1 GiB per-execution bound is a local working setting; a larger or denser source can legitimately
  end in `QUOTA_EXCEEDED`.
- Single-instance queue latency is up to the 3 s scheduler poll plus claim contention (~117 s observed
  on the 60 s clip).
- `@playwright/test` and `@axe-core/playwright` are not declared in `package.json`; browser harnesses
  need them installed explicitly.
- The full Java suite cannot complete on this host as configured (missing SC-967 fixture, no
  `chromascape_aiplayer_dev` database, container flakiness, one fork-order Mockito leak).
- 8090 is started by an external tmux watchdog, not a systemd unit; it is not automatically restarted
  after host reboot.
- Native capture (R4) and the YouTube acquisition route (R6) remain unproven.
