# SC-1618 transport diagnostics spec

The operator-visible diagnostics show source state, dropped count, and source-scoped capture ranges while keeping observation identity distinct. Retry ownership, malformed-frame counts, and stale-session transitions are recorded as bounded metadata; packet bodies remain out of logs.
