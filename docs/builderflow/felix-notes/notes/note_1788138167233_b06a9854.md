# Architecture

```mermaid
flowchart TB
  subgraph Capture
    M[Micro6 semantic dispatch hooks] --> B[TICK_BATCH actions recording-action/v1]
  end
  subgraph ChromaScape
    B --> IN[Validated idempotent ingestion]
    IN --> DB[(Snapshots logs typed actions)]
    DB --> CV[Captured or legacy inference converter]
    CV --> PF[Preflight and manifest v2 compiler]
    PF --> RW[Durable replay worker]
    RW --> ART[(Events checkpoints reports trace artifacts)]
    ART --> API[Authenticated run and viewer APIs]
    API --> UI[/replay observed versus simulated UI]
  end
  subgraph xRSPS
    RW -->|stdio deterministic contract| AD[Authoritative replay adapter]
    AD --> SV[Real movement collision action inventory dialogue skill tick services]
    ART --> OBS[WebGL REPLAY_OBSERVER data source]
    OBS --> REN[Normal xRSPS rendering pipeline]
  end
```

## Decisions

1. Simulation authority stays headless and browser-independent. The WebGL client is a read-only trace renderer.
2. Real xRSPS services are reused through an isolated deterministic composition; the synthetic kernel remains explicitly non-authoritative.
3. No replay account, login socket, SQLite write, autosave, global ticker, normal-player mutation, Micro6 control, or OpenRune fallback is allowed.
4. Existing recordings may be watchable BEST_EFFORT; only complete typed action captures can be CERTIFIED.
5. ChromaScape owns durable run truth, authentication, idempotency, leases, artifacts, and viewer-token issuance.
6. Viewer controls change local presentation only. `controlAllowed=false` is invariant.

## Trust boundaries

- Micro6 is an evidence producer, never a replay executor.
- ChromaScape validates and persists evidence and orchestrates isolated workers.
- xRSPS capability identity must pin commit, lockfile/build, cache, content, fidelity, and supported actions.
- Viewer tokens are short-lived, run-scoped, hashed at rest if persisted, and cannot call mutation APIs.
- A trace frame is accepted only after content-address verification against the run report.
