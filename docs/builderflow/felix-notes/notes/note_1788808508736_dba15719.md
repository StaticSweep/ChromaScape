# SC-1618 API Contract

```yaml
openapi: 3.1.0
info:
  title: SC-1618 packet observations and replay
  version: 2.0.0
paths:
  /ws/micro6/tick-stream:
    post:
      summary: Receive schema-v3 TICK_BATCH packets
      responses:
        '200':
          description: Durable TICK_BATCH_ACK after packet and receipt commit
  /api/debug/replay/packets/{sessionId}:
    get:
      summary: Cursor-paginated persisted packet observations
      parameters:
        - {name: sessionId, in: path, required: true}
        - {name: tick, in: query, required: false}
        - {name: startTick, in: query, required: false}
        - {name: endTick, in: query, required: false}
        - {name: direction, in: query, required: false}
        - {name: protocolName, in: query, required: false}
        - {name: opcode, in: query, required: false}
        - {name: decodeStatus, in: query, required: false}
        - {name: search, in: query, required: false}
        - {name: cursor, in: query, required: false}
        - {name: limit, in: query, required: false}
      responses:
        '200':
          description: Bounded page ordered by tick, source, and observation identity
        '409':
          description: Permanent packet identity conflict
```

The list response excludes raw sanitized payloads by default. Retry with identical identity and content is idempotent; changed content under one identity is rejected permanently.
