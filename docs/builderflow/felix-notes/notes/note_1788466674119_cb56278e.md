## 5. Junction policy decision: CONTAINMENT (documented in code javadoc)

- Contract: symlinks always rejected; junctions/reparse points permitted ONLY when every
  existing component resolves via toRealPath() to a canonical target inside the trusted
  root; escapes rejected; uninspectable fails closed.
- Proof sketch: (1) existing-path entries return canonical toRealPath() and callers must
  retain/use it; (2) subsequent reads use retained real path with NOFOLLOW_LINKS;
  (3)-(4) missing-leaf/atomic-promotion TOCTOU cannot be fully eliminated with standard
  NIO — mitigated by ancestor revalidation immediately before use, NOFOLLOW on every
  check, retained real paths, ATOMIC_MOVE; residual window documented.
- Strict "reject every junction" NOT adopted: undetectable reliably with standard NIO
  (dos:reparsePoint throws IllegalArgumentException on native Windows for ordinary files),
  breaks legitimate in-root Windows layouts, and does not close the post-validation
  retarget window either. Test TaskSourcePathSecurityTest:141 (in-root junction remains
  contained, outside junction rejected) is CONSISTENT with this decision and was kept.
