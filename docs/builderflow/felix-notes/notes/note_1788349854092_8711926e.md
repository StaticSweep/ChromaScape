## Root cause

Two nested test application classes are annotated with `@SpringBootConfiguration`:

1. `C:\Dev\IdeaProjects\ChromaScape\src\test\java\com\chromascape\web\gameplay\orchestration\accountbuilder\JpaAccountBuilderOrchestrationStoreTest.java:588`
2. `C:\Dev\IdeaProjects\ChromaScape\src\test\java\com\chromascape\web\gameplay\orchestration\accountbuilder\AccountBuilderOrchestrationPostgresConcurrencyTest.java:434`

Both register a bean named `orchestrationStore`. Because `@SpringBootConfiguration` is a production-discoverable `@Configuration`, unrelated `@SpringBootTest` application contexts see both nested test configurations. Startup fails with `BeanDefinitionOverrideException` before those tests execute.

Do not solve this by enabling bean overriding, renaming one bean, weakening assertions, excluding failing suites, or deleting test coverage. The test configurations must be invisible to ordinary component scanning.
